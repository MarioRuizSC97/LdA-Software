# Consultar los movimientos de inventario

Aquí puedes revisar los cambios de inventario, filtrar por sucursal y asignar o corregir el nombre que aparece para un vendedor. Esta pantalla está disponible para el administrador.

## Paso a paso

1. Pulsa **Movimientos** en la barra superior o en **Menú**, según tu pantalla. Verás la lista de movimientos.
2. Abre el selector de sucursal, que inicialmente muestra **Todas**, y elige una sucursal. Verás la lista correspondiente; selecciona Todas para volver a consultar el conjunto.
3. Revisa cada movimiento. Verás el tipo, el producto, la cantidad con su signo y unidad, la sucursal, la fecha y la persona responsable. Las entradas y los traslados muestran **Administrador** como responsable.
4. Pulsa **Actualizar** para consultar de nuevo los movimientos. Verás la lista recargada con el filtro que mantengas seleccionado.
5. Si aparece **Asignar nombre** o **Editar nombre** junto a un vendedor, pulsa esa acción. Verás un cuadro con el campo **Nombre del vendedor**.
6. Escribe un nombre y pulsa **Guardar**. Si se confirma, el cuadro se cerrará y verás el nombre actualizado en los movimientos cargados de ese vendedor. Si pulsas **Cancelar**, regresarás a la lista sin confirmar el formulario.
7. Pulsa **Volver** o **Inicio** para salir. Verás el panel anterior o el catálogo, respectivamente.

## Notas

- Las cantidades positivas representan entradas y las negativas, salidas. Los traslados aparecen como **Traslado (salida)** en origen y **Traslado (entrada)** en destino.
- Las filas del administrador no ofrecen las acciones para cambiar el nombre de un vendedor.
- En pantallas amplias puedes consultar un resumen del filtro y de los movimientos cargados.
- La revisión visual de esta pantalla en la aplicación está pendiente; las instrucciones se contrastaron con la pantalla y las pruebas disponibles.

## Si algo no funciona

- **No hay movimientos**: la consulta actual no tiene registros para mostrar.
- **No se pudieron cargar los movimientos**: pulsa **Reintentar** para consultar de nuevo.
- **Movimiento ilegible**: la aplicación no puede presentar ese registro como un movimiento válido; no lo interpretes como una cantidad de cero.
- **Escribe un nombre de 1 a 120 caracteres.**: corrige el nombre antes de guardar.
- **No se pudo confirmar el cambio. Reintenta con el mismo nombre.**: el campo queda sin posibilidad de edición. Pulsa **Reintentar** para confirmar el mismo cambio, sin escribir otro nombre.
