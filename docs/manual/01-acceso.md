# Acceder a LDA Inventory

Aquí puedes iniciar sesión con tu cuenta de la tienda para consultar el catálogo y utilizar las opciones disponibles para tu perfil.

## Paso a paso

1. Abre la aplicación. Si no tienes una sesión activa, verás el formulario de **Inicio de sesión**.
2. Escribe tu correo en **Correo electrónico**. Verás la dirección que has introducido.
3. Escribe tu contraseña en **Contraseña**. Los caracteres quedarán ocultos.
4. Pulsa **Iniciar sesión**. Mientras se comprueba tu acceso, verás un indicador de espera; si se acepta, aparecerá el catálogo y tu perfil en la barra superior.
5. Cuando termines, pulsa **Cerrar sesión**; si no ves esa opción en la barra superior, búscala en el menú. Volverás al formulario de acceso.

## Notas

- Las opciones dependen de tu perfil. Solo el administrador puede crear productos.
- Si tu sesión sigue activa al abrir la aplicación, puedes entrar directamente al catálogo sin completar el formulario de nuevo.

## Si algo no funciona

- Si dejas el correo o la contraseña vacíos, aparece **«Ingresa el correo y la contraseña de demostración local.»**. Completa ambos campos y pulsa **Iniciar sesión**. Ese es el texto actual del aviso, aunque no estés usando una demostración.
- Si aparece **«No se pudo iniciar sesión.»**, revisa los datos introducidos y vuelve a intentarlo.
- Si aparece **«Sesión rechazada»**, pulsa **Volver a iniciar sesión**. Verás de nuevo el formulario de acceso.
- Si aparece **«No se pudo verificar la sesión»**, no se muestra el catálogo. Pulsa **Reintentar** si está disponible para volver a comprobar tu acceso.
