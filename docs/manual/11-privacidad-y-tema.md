# Proteger la vista de costos y personalizar la apariencia

Aquí puedes usar un PIN para evitar mostrar costos por accidente, cambiar la apariencia y orientarte con los controles de navegación. El acceso a costos corresponde al administrador; el PIN no cambia los permisos de tu cuenta.

## Paso a paso

### Crear, usar y cambiar el PIN

1. Como administrador, abre la ficha de un producto y pulsa **Ver costo**, o pulsa **Registrar entrada de inventario**. Si es la primera vez en este equipo, verás **Crea un PIN**.
2. Escribe de cuatro a seis dígitos en **PIN** y repítelos en **Confirmar PIN**. Pulsa **Continuar**; si coinciden, verás el costo disponible o el formulario de entrada que solicitaste.
3. Si ya tienes un PIN, verás **Ingresa el PIN**. Escríbelo en **PIN** y pulsa **Continuar**; si es correcto, se abrirá únicamente la vista que solicitaste. **Cancelar** cierra la solicitud sin mostrar el costo ni abrir la entrada.
4. Para cambiarlo, entra al formulario de inventario y pulsa **Cambiar PIN**. Verás **PIN actual**, **PIN nuevo** y **Confirmar PIN**; completa los tres y pulsa **Guardar PIN**. Si se acepta, el cuadro se cerrará y el PIN nuevo sustituirá al anterior.
5. Sal del formulario con **Volver** o **Inicio**, o cierra la ficha del producto y vuelve a abrirla. Verás que el costo vuelve a estar oculto o que necesitas introducir el PIN otra vez para registrar una entrada.

### Cambiar el tema y navegar

1. Abre **Menú** cuando esté disponible. Verás las acciones de tu cuenta; pulsa una para abrir su pantalla. **Cerrar menú** o tocar fuera del panel lo cierra.
2. Localiza el botón de tema, en el menú o en la barra superior según tu pantalla. Verás el estado **Tema: Sistema**, **Tema: Claro** o **Tema: Oscuro**.
3. Pulsa el botón de tema para cambiar de Sistema a Claro, de Claro a Oscuro y de Oscuro a Sistema. Verás el nuevo estado y la apariencia correspondiente; Sistema sigue la apariencia del equipo y la elección se conserva para próximas aperturas.
4. Desde un panel abierto, pulsa **Volver** para regresar al panel anterior o **Inicio** para regresar al catálogo. Verás el destino correspondiente; durante un envío estos controles pueden quedar desactivados.
5. Pulsa **Actualizar catálogo**, en el menú o en la barra superior, para consultar de nuevo los productos. Verás el catálogo actualizado cuando finalice la carga. **Cerrar sesión** permite salir de tu cuenta.

## Notas

- El PIN se guarda en este equipo: es una ayuda de privacidad visual, no sustituye el inicio de sesión ni los permisos de tu cuenta. No deja todos los costos abiertos de forma permanente.
- Si olvidas el PIN, la propia aplicación indica que debes borrar los datos de la app en este equipo. No hay una opción de recuperación del PIN en este cuadro; antes de borrar datos, solicita ayuda para revisar las consecuencias.
- El vendedor no dispone de **Ver costo**.
- La revisión visual de estas pantallas en la aplicación está pendiente; las instrucciones se contrastaron con las pantallas y las pruebas disponibles.

## Si algo no funciona

- **El PIN debe tener de 4 a 6 dígitos.**: usa únicamente números y respeta esa longitud.
- **Los PIN no coinciden.**: vuelve a escribir el mismo PIN en ambos campos del PIN nuevo.
- **PIN incorrecto.**: revisa el PIN introducido; para cambiarlo también debes proporcionar el PIN actual correcto.
- **No se pudo leer el PIN. Intenta de nuevo.** o **No se pudo guardar o verificar el PIN. Intenta de nuevo.**: cierra el cuadro con **Cancelar** y vuelve a abrir la acción.
- **Costo no disponible** después de introducir el PIN: la vista se autorizó, pero no hay un costo disponible para mostrar; no significa que el costo sea cero.
