## Specs
- S1. Visual scope. User: "Meterle algún diseño más elegante a la interfaz en general". Accepted suggestion: "Detalles más compactos. Ahora el panel ocupa casi toda la altura y deja mucho espacio vacío. Lo ajustaría al contenido, con nombre y precio destacados y el QR en una sección propia."
- S2. Accepted suggestion: "Precio con mayor protagonismo. En las tarjetas, distinguiría mejor nombre, precio y existencias: precio más visible y stock como información secundaria."
- S3. Accepted suggestion: "Diferenciar las acciones. “Detalles” y “Agregar” tienen casi el mismo peso visual. Haría Agregar el botón principal y Detalles una acción más discreta."
- S4. Accepted suggestion: "Más contraste entre fondo y tarjetas. Propondría fondo gris muy suave, tarjetas blancas y azul reservado para acciones importantes. Elegante, sin recargar ni depender de sombras fuertes."
- S5. Accepted suggestion: "Mantener uniforme la cuadrícula. En escritorio, el último producto solitario se estira por toda la fila. Conservaría el ancho de las demás tarjetas."
- S6. Accepted suggestion: "Animaciones breves y útiles. Suavizar el cambio de “Agregar” al selector, las actualizaciones de cantidades y la apertura de paneles. Sin rebotes excesivos ni retrasar el trabajo, respetando la preferencia de reducir movimiento."
- S7. Platform intent. User: "si tambien se pueden pasar esas animaciones a Android e iOS muchisimo mejor". Keep shared Flutter presentation; check Android/iOS widget layouts and use an available native simulator when practical. Narrow web is not native proof.
- S8. Iteration authorization. User: "Dale papurri empieza con los cambios igual si lo ves necesario paraleliza cosas con más de un agente ya sea usando el perfil opensource, openai o claude ahora si que para ver el resultado en menos tiempo, ahora si que si al final veo algo que en dado caso necesite cambios o siga cierto formato te lo hago saber y vamos cambiandolo sobre la marcha papurri :)"
- S9. Panel transitions. User (2026-10-21): "me gustaria que tuviera transiciones más suaves a la hora de estar navegando entre paneles". Body panel changes (Correcciones, Movimientos, transfer form, Avisos de traslados, cart, receipt, creation/pricing/intake and back to the catalog via Volver/Inicio) cross-fade with a short vertical settle; reduced motion switches instantly.
- S10. Scroll fade. User (2026-10-21): "tambien tener la posibilidad de que el panel donde se muestran los productos aparezcan o desaparezcan segun se hace scroll en el inventario no se algo como un tipo de opacidad en blanco en la parte de abajo para que se logre ese efecto igual revisalo con ego-browser para que veas como hacerlo papurri :)". Assumption: a bottom fade (to the page background) over the product list while more content lies below, plus a slimmer top fade once scrolled; static gradients, no extra motion.
- S11. Softer Agregar. User (2026-10-21): "Tambien otra cosa que me gustaria es que el boton de agregar no resalte tanto no sé si se pueda cambiar ese color o que tuviera una transicion de color más suave entre el boton y la ficha del producto que lo siento muy chirriante :S". 'Agregar' keeps being the primary card action but uses the tonal fill (secondaryContainer) instead of solid primary.
- S12. Search focus mode. User (2026-10-21): "darle el foco al buscador cuando se intenta buscar algo dentro del inventario sombreando lo demás del panel y cuando te arroje el resultado de la busqueda te aparezca como cuando vas a consultar el detalle de producto con el fondo difuminado y así :)". Decision (L17): results show the full catalog cards (price, stock, Agregar, Detalles) so selling works straight from the search.
- S13. Search mode dims the whole screen. User (2026-10-21): "en el modo busqueda solamente una parte se oscurece y el header queda en blanco y queda algo raro a mi parecer". The scrim also covers the app bar and the cart bar; only the search field and its results stay bright.
- S14. Results width. User choice (2026-10-21): "Igual al buscador (Recomendado)" — on desktop the results card has the same width and edges as the search field (today ~560 px, left-aligned under a ~920 px field).
- S15. Slower panel transitions. User: "con respecto a las transiciones siento que estan algo rapidas entre panel y panel"; choice "350 ms (Recomendado)" (was 220 ms).
- S16. Smoother scrolling. User: "que al hacer scroll hacía arriba y abajo se vea más suave y que no sea tan abrupto a la hora de bajar"; choice "En ambos": smooth mouse-wheel scrolling on web (each wheel step animates instead of jumping) and a smooth finger scroll on Android/iOS.
